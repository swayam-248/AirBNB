# AirBNB Clone

A modern, full‑stack clone of the popular **AirBNB** platform built with **Node.js** and **Express** on the backend, and a **React** frontend. This project demonstrates clean architecture, RESTful APIs, user authentication, listing management, and booking workflows.

## Project Overview

The **AirBNB Clone** provides a minimal yet functional recreation of AirBNB's core capabilities:
- User registration & authentication (JWT)
- Property listings with photos, description, price, and availability
- Search & filter listings by location, dates, and price range
- Booking flow with payment simulation
- User dashboard for managing listings and reservations

The codebase is intentionally modular to serve as a learning resource or a solid foundation for further feature expansion.

---

## Features

- **RESTful API** built with Express.js
- **MongoDB** for data persistence (via Mongoose)
- Secure password handling with **bcrypt**
- JWT‑based authentication & route protection
- Server‑side input validation using **Joi**
- **React** frontend with React Router v6
- Responsive UI built with CSS Grid & Flexbox
- Docker configuration for easy containerised development

## Getting Started

### Prerequisites

- **Node.js** (v18 or later) – [download](https://nodejs.org/)
- **npm** (comes with Node) or **yarn**
- **MongoDB** instance (local or cloud)
- **Git**

### Installation

```bash
# Clone the repository
git clone https://github.com/swayam-248/AirBNB.git
cd AirBNB

# Install backend dependencies
cd server
npm install   # or yarn install

# Install frontend dependencies
cd ../client
npm install   # or yarn install
```

### Environment Variables

Create a `.env` file inside `server/` with the following keys (replace placeholder values):

```dotenv
PORT=5000
MONGODB_URI=mongodb://localhost:27017/airbnb_clone
JWT_SECRET=your_secret_key_here
```

## Running the App

```bash
# From the project root
# Start the backend (will run on http://localhost:5000)
cd server
npm run dev   # or nodemon

# In a new terminal, start the frontend (http://localhost:3000)
cd ../client
npm start
```

Open your browser and navigate to **http://localhost:3000** to explore the application.

## API Documentation

The backend exposes a set of REST endpoints under the `/api` namespace. Main groups include:
- **Auth**: `/api/auth/register`, `/api/auth/login`
- **Listings**: `/api/listings` (GET, POST, PUT, DELETE)
- **Bookings**: `/api/bookings` (GET, POST)
- **Users**: `/api/users/me`

For detailed request/response schemas, refer to the `docs/api.md` file (generated by Swagger).
